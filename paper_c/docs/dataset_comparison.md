## 建议

**以 BDD-OIA 作为核心主张（过曝 → 修复 → 零标签规程修改）的主数据集；InspecSafe 作为主要应用数据集；MMAD 作为泛化与剂量–反应数据集。**

理由：
1. BDD-OIA 是三个里唯一能**无循环论证地**把论文三步主张一次性检验完的数据集：原子同时出现、有真值、有自然的规程修改。效应也最直观：规程一改，只用判定训练的模型比零样本还差，修复后 +65 点，可以直接做图 1。
2. 它让我们与最接近的工作（推理捷径 / rsbench）在同一个基准上对话：他们在合成数据上演示“改规则暴露捷径”，我们在真实图像上定量刻画并修复。这比任何新数据集更能回应审稿人“这不就是推理捷径吗”的质疑。
3. InspecSafe 仍然不可替代：真实的工业规程、按行业变化的严重度表、跨行业迁移、新隐患、效率，正好对应“工业检测”的应用动机。它也是规程最复杂的数据集（序数 max）。但它的规程修改实验在 V36 回收前有循环论证，原子标签也不完整，不适合作为核心主张的唯一证据。
4. MMAD 补充第二种原子来源、精确标签和剂量–反应规律，但它没有原子同时出现、没有自然的规程修改，不适合当主数据集。
