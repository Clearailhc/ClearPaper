# PRISM-SFT 的分支监督：与规程无关的正例–无标签学习（PU）

> 方法组件，替代原来的“等级约束弱标签”。动机与证据见研究日志 #38、#42、#43；预注册见 #44。

## 1. 问题：等级约束标签让感知依赖规程

记 o_j(x) ∈ {0,1} 为图像 x 中原语 j 是否真实存在。PRISM 的合并层假设分支输出估计的是**与规程无关**的后验 p_j(x) = P(o_j = 1 | x)，规程只出现在判据表 s(g, j) 里。

原来的分支标签（等级约束）只在三种情况下给出：
- 描述提到 → 1；
- s(g, j) > y（严重度高于场景等级）→ 0；
- 正常图 → 0。

是否有标签，记为 M_j。M_j 依赖于场景等级 y 和判据表 s，属于**非随机缺失**。训练得到的是 p_θ(o_j | x, M_j = 1)。在被掩盖的区域（隐患图，0 < s ≤ y，描述没提到）：

  E[o_j | M_j = 1, 隐患图, s ≤ y] = 1，

即这个区域里**没有任何负样本**，最优解是“隐患图上都答是”。实测被掩盖格子的误报率从零训练的 13.9% 升到 29.5% / 40.5%（#43）。

由于 M 依赖于训练时的判据表 S_train，学到的感知也依赖 S_train。规程或行业一变，被掩盖的格子成为决定性原语，误报就暴露出来（R2 降级、隧道留一行业）。

## 2. 方法：与规程无关的 PU 监督 + 标注频率修正

### 2.1 标签（只用描述，不用判据表）

对每个（图像，原语）格子定义观测标签 ℓ_j：
- 描述提到存在 → ℓ_j = 1（**有标注的正例**）；
- 其他格子 → ℓ_j = 0。这包括正常图的全部格子（干净负例），以及隐患图上未提及的格子（**无标签**，混有未被写出的真实隐患）。

每个格子都有观测值，M ≡ 1，判据表不参与。训练目标是标准的逐分支二元交叉熵，模型学到的是 g_j(x) = P(ℓ_j = 1 | x)。代码：`train_lora.py --branch-labels closed_world`。

### 2.2 Elkan–Noto 修正

**假设（SCAR，正例被标注的部分是完全随机抽取的）**：一个真实存在的原语是否被写进描述，与图像无关，概率为常数 c_j = P(ℓ_j = 1 | o_j = 1)。由于 ℓ_j = 1 ⇒ o_j = 1：

  g_j(x) = P(ℓ_j = 1 | x) = P(ℓ_j = 1 | o_j = 1, x)·P(o_j = 1 | x) = c_j · p_j(x)，

所以 **p_j(x) = g_j(x) / c_j**（Elkan & Noto, KDD 2008，引理 1）。

c_j 的估计用 Elkan–Noto 的 e₁ 估计量：在验证集有标注的正例上，c_j ≈ E[g_j(x) | ℓ_j = 1]。若某原语在验证集中的正例少于 5 个，用全部原语合并估计。注意 e₁ 假设有标注的正例上 p_j ≈ 1（隐患一旦被写出就几乎确定存在），否则 ĉ_j = c_j·E[p_j | ℓ_j = 1] 会偏低，导致修正过度；这一点由修正后正常图误报率是否上升来检查。

推理时，把分支对数几率 z_j = log P(Yes) − log P(No)（即 g_j = σ(z_j)）换成

  z̃_j = logit( min(1 − ε, σ(z_j) / ĉ_j) )，

再送入原有的逐分支校准和行业条件 noisy-OR 合并。代码：`jevc/ideas/pu_branch.py`。

### 2.3 性质
1. **与规程解耦**：标签和修正都不用判据表；换表或换行业时，感知部分不变，只换合并层的表。
2. **排序不变**：g_j 是 p_j 的常数倍，所以每个原语的 AUROC 不受 c_j 影响。修正只纠正尺度，也就是在固定阈值或合并时的召回。
3. **无额外训练**：只在验证集上估计 J 个常数。

### 2.4 假设何时会被破坏
SCAR 要求“是否被写出”与图像无关。不显眼的隐患（烟头、小块异物）更容易漏写，此时 c_j 会随图像变化，修正后仍会低估小目标。可检验的信号：
- 修正后，原语召回是否回到等级约束版本的水平；
- 同时，被掩盖格子的误报率是否仍明显低于等级约束版本。

若 SCAR 严重不成立，可以改用依赖实例的 PU 方法（例如按目标大小或显著性分层估计 c_j），列为后续工作。

## 2.5 实测（#45）：修正被逐分支校准吸收
- 验证集估计的 c_j 为 0.80–0.99（多数 0.90–0.95），描述几乎列全了隐患。
- 显式修正后，原语召回、误报、同分布准确率与 R1 / R3 都不变，R2 0.558 → 0.581（不显著）。
- 原因：p = g / c 在 g 不大时，于 logit 空间近似平移 −log c_j，正好被 PRISM 已有的逐分支偏置 b_j 吸收。
- **最终形式**：只用描述的观测标签（2.1）+ PRISM 原有的逐分支校准。PU 理论说明这一估计量与规程无关、在 SCAR 下一致到常数，而常数由校准层吸收；显式 Elkan–Noto 修正不需要（作为消融报告）。

## 3. 与相关工作的关系
- PU 学习：Elkan & Noto（2008）；无偏 / 非负风险估计 uPU / nnPU（du Plessis et al., 2015；Kiryo et al., 2017）；多标签缺失标签（例如 “assume negative” 基线与其修正）。
- 区别：我们指出的问题是**由规程引起的非随机缺失**——用规程推出的弱标签会让感知依赖规程。PU 形式恰好把规程从监督信号中移除，这与 PRISM 的“感知与规程解耦”一致。
