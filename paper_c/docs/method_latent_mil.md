# PRISM-SFT 的训练：把规程当作已知观测信道的隐变量最大似然（latent MIL）

> 方法组件，统一并取代“等级约束标签”“封闭世界标签”“显式 PU 修正”“整图联合损失”等局部修补。动机见研究日志 #38、#42、#43、#46，预注册见 #47。

## 1. 生成过程

对行业为 g 的图像 x：

| 部分 | 定义 | 含义 |
|---|---|---|
| 感知 | o_j ~ Bernoulli(p_θ,j(x))，j = 1..J，给定 x 条件独立 | 要训练的就是 p_θ |
| 泄漏 | ℓ_k ~ Bernoulli(λ_k)，k = 1..K−1 | 原语清单之外的隐患 |
| 规程信道（已知） | R = max( max_j s(g, j)·o_j , max_k k·ℓ_k ) | 判据表 s 只出现在这里 |
| 标注噪声 | y = R（概率 1 − ε），否则在 K 级上均匀 | 标注与判据表不一致（#38 约占 15%–20% 的错误） |
| 提及信道 | P(m_j = 1 \| o_j = 1) = c_j，P(m_j = 1 \| o_j = 0) = δ | 描述是否写出该隐患；c_j 为提及率，δ 为误提及率（例如把工艺烟雾写成“冒烟”） |

推理时的 PRISM（逐分支概率 + 行业条件 noisy-OR）正是这个生成过程中 P(R | x) 的前向计算。

## 2. 训练目标：观测数据的边际似然

  L(θ) = Σ_i log P(y_i, m_i | x_i) = Σ_i log Σ_o ∏_j P(o_j | x_i) P(m_ij | o_j) · P(y_i | o, ℓ)

**闭式解。** 由于 R 是取最大，累积概率按原语分解：

  P(R ≤ k, m | x) = Λ(k) · ∏_j f_j(k)，

其中 Λ(k) = ∏_{t > k}(1 − λ_t)，f_j(k) = P(o_j = 0, m_j) + 1[s(g, j) ≤ k]·P(o_j = 1, m_j)，并且

  P(o_j = 0, m_j) = (1 − p_j)·(δ 若 m_j = 1，否则 1 − δ)，
  P(o_j = 1, m_j) = p_j·(c_j 若 m_j = 1，否则 1 − c_j)。

于是 P(R = y, m) = P(R ≤ y, m) − P(R ≤ y − 1, m)，加上标注噪声后，

  P(y, m) = (1 − ε)·P(R = y, m) + (ε / K)·∏_j [P(o_j = 0, m_j) + P(o_j = 1, m_j)]。

后验 q_j = P(o_j = 1 | x, y, m) 用同样的方法得到：把第 j 个因子换成“o_j = 1”的项。代码见 `jevc/ideas/latent_mil.py`，单元测试与穷举法逐项一致。

## 3. 优化：EM
- **E 步**：用当前模型的分支概率（在验证集上用基础 noisy-OR 校准）计算每个（训练图，原语）格子的后验 q_ij。脚本：`scripts/em_targets.py`。
- **M 步**：以 q_ij 为软目标，最小化 Bernoulli 交叉熵 −[q log σ(z) + (1 − q) log σ(−z)]，z 为首个答案 token 的 Yes 与 No 的 logit 之差。脚本：`train_lora.py --mode branches_soft`。
- EM 单调不降地优化同一个边际似然。第 1 轮从零训练基座的分支概率出发。由于每轮都要先在训练集上做一次推理，再训练一次，成本约为原 PRISM-SFT 的 1.1 倍。

## 4. 前面的各种做法都是它的特例

| 做法 | 等价于 |
|---|---|
| 等级约束标签 | ε = 0、c_j → 0 时，被掩盖的格子没有信息（视为缺失），s > y 的格子为 0；再加上用 override 把“提到但严重度高于等级”的原语强行改成 0 |
| 封闭世界标签（V19） | 忽略 y，c_j = 1，δ = 0 |
| 显式 PU 修正（V21） | 忽略 y，只修正 c_j 的尺度 |
| 整图联合损失（方向 6） | 似然中的 P(y \| o) 项：抬高等级的高严重度误报直接受罚 |

几个对照：
- **被掩盖的格子**（隐患图，s ≤ y，未提及）：后验 q = p(1 − c)/(1 − p·c)（不考虑 ε），既不是缺失，也不是 0。实测第 1 轮 E 步的均值为 0.055。
- **标注与判据表不一致**：由 ε 吸收，感知不会被强行改写。
- **泄漏**：用于解释“描述中没有任何清单内隐患、但等级不为 0”的图，不会把原因硬塞给某个原语。

## 5. 性质
1. **与规程解耦有构造上的保证**：s 只出现在观测信道 P(y | o)，不出现在 p_θ(o | x)。训练时把规程当作已知信道积分掉，测试时换表即可。
2. **可辨识性**：一个原语若在训练集中没有任何被描述的正样本，数据中就没有“它长什么样”的信息，p_j 不可辨识。这类原语（少于 5 个正样本）在 M 步中不计损失，保留基座的零训练能力。这是由可辨识性得出的规则，不是补丁；它在 LoRA 共享参数下是否足够，由 `96_holdnew` 检验。
3. **与已有工作的关系**：多示例学习（bag 标签为 instance 的最大值，noisy-OR MIL）的有序推广，并带有已知的、按行业变化的严重度信道；提及信道为 PU 学习（Elkan & Noto, 2008）。

## 6. 固定的超参数（事先固定，不调）
- c_j：#45 的 e₁ 估计（`configs/mention_freq.json`）；
- ε = 0.05，δ = 0.01，可辨识性阈值为 5 个正样本；
- 训练样本数与原 PRISM-SFT 相同（全量 9,570；留一行业为 3 × 图片数）；q ≥ 0.5 的格子全部纳入，其余随机抽取。
