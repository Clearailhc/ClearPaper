## 0. 一句话

**视觉决策 = 规程 ∘ 状态。** 图像决定“状态”（发生了什么），部署方决定“规程”（发生的事意味着什么）。模型应当学习对**整个规程族**都充分的视觉状态，而不是某一条规程下的结论。
- **推理**：LUX 一次读出完整状态，即并行的事实查询，再按任意规程精确“冲洗”出结论。
- **训练**：只用一条规程的结论标签去学状态，会因为规程的饱和而“过曝”，截断非决定性事实的信息。LUX 用 HDR 式训练把状态“记全”。

> 类比：直接分类器输出的是**已冲洗的 JPEG**，LUX 记录的是 **RAW**。

## 1. 背景：规程约束的视觉决策

1. **普遍存在**：工业安全分级、产品缺陷判定、合规检查、医疗分级。结论由明文规程从若干可观察事实合成：取最严重的那项、任一项不合格即判不合格、全部满足才放行。
2. **规程会变**：修订（某项升级或降级）、因站点而异（同一隐患在不同行业等级不同）、扩充（新增检查项）。这些变化**都不改变图像里发生了什么**，只改变“发生的事意味着什么”。
3. **VLM 的现状**：
   - 直接问：把规程写进提示，一次给出结论；
   - 慢思考：先生成长推理，再给结论；
   - 微调：在一条固定规程下学“图像 → 结论”。

   三者都把“状态”和“规程”压在同一个输出里。

## 2. 第一性原理：应该学什么

- 把图像对应的状态记为 s(x)，即若干事实是否成立；规程记为 π；结论为 y = π(s(x))。
- **对单一规程充分**：只要能算出 π₀ 下的结论就够了，最省的表示就是结论本身。这正是端到端训练得到的东西。
- **对规程族 Π 充分（规程充分状态）**：对 Π 中每一条规程，结论都能由这个表示算出。
- **命题（最小规程充分状态）**：当规程族足够丰富，每个事实至少在某条规程下会影响结论时，最小的规程充分状态就是事实状态 s 本身。

  **“把决策拆成事实”不是设计偏好，而是“对规程族充分”这一目标的必然结果。** 这也回应了“拆分只是问题设计得巧”的质疑。

## 3. 动机：现有做法的三个问题

| 问题 | 本质 | 证据 |
|---|---|---|
| 端到端模型规程一改就失效 | 学到的是对 π₀ 充分的“JPEG”，其他规程需要的信息被丢弃 | 零新标注换规程时，等级变化的图上只有 4%–46%；新隐患 0.12–0.25；跨到规则不同的行业掉 9–16 个点（#40、#42、#57、#62） |
| 想得深并不更准 | 慢思考每次都从头算一张“JPEG”，又慢又不稳 | 慢 11–15 倍（尾部 32–42 倍），准确率低 10–18 个点（#48） |
| 即使拆成事实，只用结论标签训练也会**过曝** | 规程的合成会饱和：结论一旦被最显著的事实决定，其余事实的信息就被截断 | 训练后，被截断位置的误报从 14% 升到 30%–41%，可见位置反而下降；规程放宽时显现（R2：0.442）（#43、#72） |

第三点是本文的核心问题。

## 4. 过曝：一个跨领域的老现象，一个新的刻画

**这不是新现象**，它在多个领域都被发现过：
- 概率推理中的**解释消除**（Pearl）；
- 神经符号学习中的**推理捷径**（Marconato 等，NeurIPS 2023；Bortolotti 等，2025）；
- 弱监督定位**只激活最显著的部位**（CAM 与擦除系列）；
- 多示例学习中**包级准确 ≠ 实例级准确**；
- 信息瓶颈中**只保留对当前标签充分的信息**。

**已有工作缺两样东西**：
1. 没有一个**分级**的量，告诉我们哪个事实学得差、差多少。推理捷径只数“有多少个错误解”，定位与多示例学习只有经验观察。
2. 没有研究**部署时修改规程**的后果：推理捷径的实验中知识始终固定；它们的“分布外”指的是未见过的概念组合。

**我们的刻画（过曝定理）**：
- **可见度**：给定其他事实，翻转事实 j 会不会改变结论。会，就是“可见”；不会，就是“被截断”。
- **(i) 信息**：I(Y; O_j | O_{-j}) = P(j 可见) · H(O_j)。截断时，标签对 j 没有信息。
- **(ii) 学习**：只用结论标签时，j 得到的梯度与它的可见度成正比；长期被截断的事实不可辨识。在“取最大”这类饱和规程下，这表现为**欠约束**（任何取值都拟合标签），模型会退化到场景共现带来的偏置上，比如“有隐患的场景里都答‘是’”。
- **(iii) 部署**：规程从 S 改为 S' 后，误差上界为 Σ_j v_j(S') · e_j。训练时被截断、改规程后变得可见的事实，正是误差显现的地方。由此推出：
  - **升级与降级不对称**：升级只要求检出已存在的事实，降级会让被截断的事实变得可见。R1 1.000 vs R2 0.442（#40）。
  - **跨行业掉点**：新行业的规程让另一批事实变得可见（#42）。

**一张图讲清楚**：

| 摄影 | LUX |
|---|---|
| 强光把读数打满，较暗的细节被截断 | 最显著的事实决定了结论，其余事实不可见 |
| 被截断的高光，后期无法恢复 | 训练时被截断的事实，改规程后无法补救 |
| 包围曝光（HDR） | 训练时随机改变规程，让每个事实轮流可见 |
| 点测光 | 对每个事实单独测量，不经过饱和的合成 |
| 所有帧都过曝的区域，合并后仍然丢失 | 任何规程下都不可见、也从未被测量的事实：不可辨识，交给基座的先验 |

## 5. 方法：LUX

### 5.1 推理：读出 RAW，再冲洗
1. **读出状态**：所有事实问题共享一次图像预填充，各只解码一步，得到每个事实成立的概率。单请求延迟与直接问持平（#48）。
2. **冲洗结论**：在条件独立下，任意规程的结论分布都有闭式解（取最大、或、恰好一个）。结果单调、不稀释、可审计（能指出是哪个事实决定了结论）。
3. **以正常为参照的校准**：每个事实用正常图估计自己的“底噪”。只有拆成事实之后才能做（#33、#34）。
4. **改规程**：换表即生效，不需要新标注。

### 5.2 训练：HDR 式记录状态
把规程当作已知的观测信道，写出观测数据的联合似然（适当评分，命题 3）：
1. **主曝光**：真实结论在训练规程下的对数评分，并带标注噪声项，吸收标注与规程的不一致；
2. **包围曝光**：在保持支撑集不变的随机规程下，对“描述推出的结论”做评分，让不同事实轮流变得可见。对应推理捷径文献中的“多任务、不同知识”；
3. **点测光**：描述是否提到某事实，作为不经过规程合成的逐事实观测，按行业门控，并按 PU（只有正例和无标注样本）建模。对应“概念监督”，但只需要已有的文字描述，不需要稠密标注；
4. **不可辨识的事实**：不计似然损失，用 KL 锚定基座。对应 HDR 中“所有帧都过曝的区域”。

**工程**：训练时同样共享前缀，单步提速 6–8 倍；8 卡并行，全量约 25 分钟（#55、#58）。

### 5.3 与已有方法的关系（写进相关工作）
- **概念瓶颈模型（CBM）**：我们零训练即可读出状态，合并层是已知、可编辑的规程而不是学出来的线性头，并且研究的是**规程修改**。CBM 的干预改的是概念的取值。
- **DeepProbLog / Semantic Loss / 推理捷径**：我们的训练是“经由已知知识从结论学感知”这一范式的特例，有闭式解。增量在于分级的过曝刻画、部署时修改知识，以及 PU 提及信道。
- **擦除式弱监督定位**：思路同源（让被压制的证据变得必要），我们是在规程层面而不是像素层面“擦除”。
- **Jev / System-One**：同期的“并行类型化问题 + 校准概率”产品（纯文本、无论文），我们处理视觉输入与规程层。

## 6. 贡献（v1）
1. **视角**：把规程约束的视觉决策形式化为“规程 ∘ 状态”，提出学习**规程充分状态**；证明在规程族足够丰富时，最小的规程充分状态就是事实状态。
2. **过曝定理**：在单调、饱和的规程下，给出“只用结论标签能学到多少状态”的分级信息论刻画，并推广到部署时修改规程：误差界、升级与降级不对称、跨行业。定位为对推理捷径等跨领域现象的统一定量刻画。
3. **LUX**：推理时一次读出状态、按任意规程精确冲洗，与直接问一样快；训练时用 HDR 式目标（主曝光 + 包围曝光 + 点测光）记录完整状态。
4. **部署偏移评测协议与系统实证**：规程修订、新增事实、新站点；预注册、多种子、强基线。

## 8. 边界（正文如实写）
- 同分布、标注充足时，微调的直接分类器可能仍高约 1 个点：标注中与规程不一致的部分（约 0.6 个点），忠于规程的模型拿不到；
- 没有小样本优势；
- 规程修订的优势有边界：补约 200 张重标图后，直接分类器能追平；
- 适用前提：状态可写成有限个可查询的事实，规程是明文的；整体性判断（如美观）不适用；
- 效率依赖前缀缓存；新增事实与 R3 的样本量小。

## v2 更新（2026-10-19，research_log #95）：主理论与贡献的收敛

**一句话**：为一族规程估计世界状态，而不是为一个规程拟合判定。

**三个定理**（推导见 `method_full_derivation.md` 第二版主理论）：
1. **充分性**：状态后验 P(s|x) 是同时对所有规程最优的唯一对象；直接判定只是它在一个规程下的有损投影。
2. **曝光缺口**：训练数据关于一个原子的信息正比于训练曝光，部署遗憾正比于部署曝光。两者之间的缺口就是过曝，在缺口上的格子不可辨识。
3. **最小信息补全**：在不可辨识的格子上，minimax 最优的取法是保持先验（I-投影）。它的对偶就是 LUX 的单一训练目标：主曝光 + 包围曝光 + 全格子先验填充，观测模型参数 c_j 由同一个似然用 EM 估计。

**贡献从四条收为三条**：
- **C1 问题与理论**：判定 = 规程 ∘ 状态；三个定理；过曝与"一般性的代价"都有精确刻画。
- **C2 方法（LUX）**：
  - 推理：一次 prefill，并行原子查询，可编辑规程组合；
  - 训练：一个目标函数，没有零散修正，只有 Q 和 β 两个旋钮；
  - 每一部分都是定理的推论。
- **C3 证据**：
  - 规程修改、迁移、新隐患、效率；
  - 过曝的干预证据，已在两个种子、两个版本上复现；
  - 第二数据集与第二种规程算子（MMAD，OR），即 V40；
  - 状态健康度（判定泄漏、曝光缺口）。

**明确不做**：多头 / 路由适配器 / 独立判定通路（#90）。同分布上的差距被定位为状态估计误差（#92），而不是分解本身的代价。
