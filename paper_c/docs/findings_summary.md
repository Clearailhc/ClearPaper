# Paper C（PRISM）阶段性结果与发现汇总

> 截至研究日志 #50（2026-10-17）。逐项细节见 `experiment_inventory.md`（按实验）与 `research_log.md`（按时间）。
> 除特别说明外，主干为 Qwen3-VL-8B，数据集为 InspecSafe-V1 测试集 1,250 张（正常 999 / 三级 7 / 二级 75 / 一级 169）。直接问的基线统一用矩阵缩放（最强的直接基线）；显著性为配对 Bootstrap 检验，\* 表示 p < 0.05。

## 一、一句话结论

PRISM（一次图像预填充 + 并发问 15 个是 / 否隐患原语 + 按行业判据表做 noisy-OR 有序合并）有三类表现：
- **零训练时**：比直接问更准，比慢思考又准又快一个数量级。
- **测试条件与训练条件不一致时**：明显优于端到端微调分类器，包括规程修订、新增隐患类型、跨行业部署。
- **同分布、标注充足时**：比微调后的直接分类器低约 1 个点。

方法的价值在于**把感知和规程分开**，而不是在所有条件下都更准。

## 二、成立的发现

### 1. 零训练：PRISM 优于直接问（3 个数据集、多个主干）

| 数据集 / 主干 | PRISM − 最强直接基线 |
|---|---|
| InspecSafe，Qwen3-VL-8B | 准确率 +0.022\*（0.919 vs 0.897）；AUROC +0.009（p = 0.08） |
| InspecSafe，Qwen3.5-9B | 准确率 +0.025\* |
| InspecSafe，Qwen3-VL-32B | 准确率 +0.014（p = 0.11）；风险代价 −0.118\* |
| InspecSafe，Gemma 4 E4B | AUROC +0.143\*，准确率 +0.073\* |
| MMAD，8B / 32B | AUROC +0.065\* / +0.052\* |
| SafeBuild，4 个主干 | 准确率 +0.025 至 +0.048\*（按类别平均均不显著） |

- **收益来自拆分本身**：在 MMAD 上把同样的缺陷知识全部塞进一个直接问题，AUROC 反而降到 0.731，PRISM 为 0.806。
- 幅度因任务和主干而异：InspecSafe 的 Qwen 系上只有约 2 个点，MMAD 和 Gemma 4 上大得多。

### 2. 结构化合并提供安全性和数据效率
- 分支数从 1 增加到 15，风险代价单调下降，2.02 → 0.55（3 个主干一致）。
- 高危漏报比无结构的学习头低 4–5 倍。
- 数据效率（#57 更正）：在同等的小校准预算下，PRISM 明显更稳、更好。例如 n = 20 时，8B 的 AUROC 为 0.959 vs 0.929，风险代价 0.601 vs 0.997。但 20 张校准图**不足以**追平用全部 573 张做矩阵缩放的直接问（Gemma 4 除外）。原先“20 个样本即可”的说法只对向量缩放基线成立。
- **正常参照校准**（MAD + γ）：AUROC 8 / 8 组显著提升。它只有拆分之后才能做（每个原语相当于一个以正常图为参照的异常检测器）；给直接问做同样处理没有帮助。

### 3. 想得宽，胜过想得深：又准又快

| 系统 | 8B 中位延迟（P95） | 8B 准确率 | 32B 中位延迟（P95） | 32B 准确率 |
|---|---|---|---|---|
| 直接问 | 0.29 s（0.30） | 0.897 | 1.04 s（1.07） | — |
| **PRISM（15 分支）** | **0.30 s（0.45）** | **0.919** | **1.01 s（1.04）** | **0.892** |
| 官方生成式提示 | 1.17 s（1.44） | 待测 | 8.89 s（11.3） | 待测 |
| Thinking | 4.38 s（19.0） | 0.739 | 11.4 s（33.4） | 0.786 |

- 单请求时，15 个分支几乎不增加延迟：共享图像前缀，只并行解码 1 步。
- 比慢思考快 11–15 倍（中位数）、32–42 倍（P95），同时更准，在“准确率–延迟”平面上严格占优。
- 前提：Qwen3-VL 的前缀缓存有效。Qwen3.5 和 Gemma 4 在 vLLM 下批量吞吐的优势没有兑现，单请求延迟尚未测。

### 4. 规程修订：零标注即可执行新规则
三个预注册场景：R1 手套 / 口罩升为一级（48 张图等级变化）；R2 安全帽 / 手套 / 口罩降级（43 张）；R3 玩手机 / 抽烟降级（16 张）。下表只看等级发生变化的图上的准确率。

| 系统 | R1 | R2 | R3 |
|---|---|---|---|
| **PRISM-SFT 换表（零新标注）** | **1.000** | **0.442** | **0.812** |
| Direct-SFT，旧提示 | 0.042 | 0.070 | 0.562 |
| Direct-SFT，提示里换成新规则 | 0.125 | 0.070 | 0.562 |
| 会读规则的 Direct-SFT（用随机规则表训练，V18） | 0.458 | 0.256 | 0.750 |
| Direct-SFT + 200 张重标图再微调 + 重新校准 | 0.979 | 0.558 | 0.688 |
| Direct-SFT 在全部重标数据上重训（上界） | 0.938 | 0.651 | 0.250 |

- 微调后的直接分类器基本不读提示里的规则：规则已经学进了权重。
- 即使是专门训练过读规则的对手，零标注时 PRISM 仍在 R1（+0.54\*）和 R2（+0.19\*）上显著领先。
- 边界：补 200 张以上重标图后，直接分类器能追平；R2 上全量重训后反超。

### 5. 新增隐患类型：零样本扩展
训练时既不给这种隐患的图片，也不训练对应的问题；只看等级完全由该隐患决定的测试图。

| 留出的隐患 | 直接分类器 | PRISM |
|---|---|---|
| 抽烟（16 张） | 0.250 | **0.875**（+0.625\*） |
| 非机动车（25 张） | 0.440 | **1.000**（+0.560\*） |

复核（#57）：校准时也从验证集剔除含该隐患的图后，抽烟为 0.250 vs 0.938，非机动车为 0.120 vs 1.000；结论更强。此时 PRISM 给出的是误报受控的检测，不是校准概率。

PRISM 只需加一个问题和一行判据表。不训练的原语在 LoRA 微调后仍保留零训练能力。

### 6. 跨行业部署：总体显著有利
训练和校准都不用留出行业的数据：

| 留出行业 | PRISM | 直接分类器 | 差值 |
|---|---|---|---|
| 油气（同时是跨机器人平台） | 0.955 | 0.829 | +0.127\* |
| 煤炭输送 | 0.896 | 0.826 | +0.070\* |
| 电力 | 0.986 | 0.981 | +0.005 |
| 隧道 | 0.905 | 0.934 | −0.028\* |
| **四折合并** | **0.930** | **0.889** | **+0.041\***（隐患图 +0.100\*） |

机制：直接分类器把训练行业的规则带进新行业。例如在油气，它把 65 张一级图里的 33 张判成二级，因为其他行业里缺 PPE 至多算二级。**新行业的规则和训练行业差得越多，PRISM 的优势越大。**

### 7. 可审计的判定依据
PRISM-SFT 给出的决定性原语与人工描述一致的比例为 84% / 76%（两个种子），判对等级时为 90% / 87%。直接分类器没有对应的输出。

## 三、不成立或负面的结果（如实报告）

| 假设 | 结果 |
|---|---|
| 同分布、标注充足时 PRISM 也更好 | ✗。Direct-SFT 0.973 / 0.970，PRISM-SFT 0.960 / 0.959（显著落后约 1 个点）；Gemma 4 上 0.946 vs 0.934 |
| 小样本优势 | ✗。Direct-SFT 用 50 张训练图就追平零训练 PRISM；50 / 200 / 800 张时两者都不显著 |
| 长尾等级（三级） | ✗。测试集只有 7 张，所有微调模型都是 0/7 |
| 训练后校准度更好 | ✗。Direct-SFT 的 ECE / RPS 更好 |
| 慢模型做分支级复核 | ✗。同等调用次数下，不如整图交给慢模型 |
| 混合聚合、良性解释原语、EM 先验自适应 | ✗。MMAD 上过拟合 / 漏报翻倍 / 无帮助 |
| 显式 PU 修正、未训练原语回退到基座 | ✗。修正被逐分支校准吸收 / 两个模型尺度不一致 |
| 慢思考普遍无用 | 部分更正：32B 和 SafeBuild 上慢思考有帮助，但仍低于 PRISM |
| 成本优势普遍成立 | 部分成立：只在 Qwen3-VL 上兑现 |

## 四、失效模式与机制（来自坏例分析）

1. **决定性原语脆弱**（训练后反超的主因，#38）：等级取决于最严重的那一个原语。难判的小目标（抽烟）一翻转，等级就整体跳变。抽烟在两个种子之间从漏检 10 次翻到误报 13 次。结构天花板（0.954–0.965）不是主因。
2. **被掩盖的误报**（#43）：原来的分支标签由判据表推出，只有原语严重度高于场景等级时才有负样本。在被掩盖的格子里，模型学成了“隐患图上都答是”。这类格子的误报率从零训练的 13.9% 升到 29.5% / 40.5%。规则一放宽（R2），或者换到规则不同的行业（隧道的“硬质异物”），这些误报就暴露出来。
3. **只有负样本的坍塌**（#46）：改用“没提到就算不存在”的标签可以修复第 2 条，但只在少数行业出现的原语，去掉那个行业后只剩负样本（非机动车召回掉到 0.28）。
4. **统一修复的尝试：latent MIL**（#47、#50）。把判据表当作已知观测信道，原语是否存在当作隐变量，训练目标是边际似然，用 EM 优化。前面的各种标签方案都是它的特例。
   - 修好了 R2（0.442 → 0.628\*）和隧道折（0.905 → 0.937，与直接分类器持平）；被掩盖的误报降到 12.7%。
   - 但油气折变差（0.955 → 0.918），同分布 0.958。
   - 按预注册条件，不取代主方法，作为分析和消融。

## 五、可信度说明与局限
- **泄漏**：7 张图字节完全相同、横跨训练和测试；5%–20% 的测试图是近似重复。但用最近邻训练图的等级去猜只有 0.846，解释不了 Direct-SFT 的高分。剔除后重算尚未完成（V7c）。
- **规则变更的真值**：由人工描述按新表推出，只用描述与官方表一致的 1,192 张图（一致率 96.8%），属于有原则的合成真值。
- **样本量**：新隐患只有 16 / 25 张，R3 只有 16 张，三级只有 7 张，置信区间都较宽。
- **单种子**：latent MIL、V18、V19 及各迁移实验大多只有一个种子。
- **事后选择**：混合聚合、标注量曲线的统一校准是看过结果后才提出的，已标为探索性。

## 七、对论文立意的含义
- 有数据支撑的表述：**将隐患感知与行业规程显式解耦**。
  - 端到端微调把两者学进同一组权重，同分布下略优（约 1 个点）；
  - 一旦规程修订、新增隐患、换到规则不同的行业，PRISM 无需新标注即可适应，而且比慢思考又准又快一个数量级。
- 需要避免的表述：“全面更准”“小样本更好”“压倒性”。隧道折、R2、同分布这几处劣势应如实呈现，并配上机制解释。
