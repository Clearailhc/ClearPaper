# V36 人工重标：标注说明

**目的**：检验“规程修改后的新等级”。论文原来的新标签是程序把规程表套在文字描述上推出来的，审稿人可能质疑循环论证。现在请你直接看图、按给定规程判等级。你的标注将作为真值，用来重新评测各个方法。

## 文件
- `V36_标注表.csv`：用 Excel 或 WPS 打开，共 128 行，每行一张图；
- `images/`：图片，文件名与“编号”一致（S001.jpg …）。

## 每一行怎么标（约 30 秒一张）
1. 打开对应图片（如 `images/S001.jpg`）。
2. 看“行业”和三列规程：**一级 / 二级 / 三级隐患**分别列出了这个行业、这条规程下属于各等级的隐患。
   - 注意：同一种隐患在不同行，等级可能不同（例如“未戴手套”有的行是一级，有的行是三级）。这是故意的，因为规程代号不同（Reg-A / B / C）。**请严格按本行写的等级判断，不要按常识或其他行。**
3. 在图中找出存在的隐患，取其中**等级最高**的一个作为整张图的等级：
   - 有任何一级隐患 → 填 **3**；
   - 没有一级、但有二级 → 填 **2**；
   - 只有三级 → 填 **1**；
   - 本行列出的隐患一个都没有 → 填 **0**。
   - 图中出现了本行没有列出的问题，**不计入**（可以写在备注里）。
4. 填“把握”：1 = 不确定（看不清、可能有可能没有），2 = 较确定，3 = 很确定。
5. “备注”可选：例如“左下角疑似有人吸烟，太小看不清”“地面反光，不确定是积水”。

## 几个容易出错的地方
- **人员防护**（安全帽、手套、口罩）：只要画面中有任何一个人员明显未佩戴，就算存在；人员背对、被遮挡、太小无法判断时，按“不存在”处理，并在把握里填 1。
- **积水 / 漏油 / 油污**：地面反光不等于积水。能看出液体痕迹或水洼才算。漏油指从设备或管道流出，油污堆积指地面长期的油渍。
- **吸烟 / 使用手机**：要能看出手持香烟或手机的动作。
- **异物**：轻质 = 塑料袋、瓶子、泡沫、纸等；硬质 = 木块、金属件等。设备本身的部件不算。
- **画面上的时间水印、相机文字**忽略。

## 请不要
- 不要参考其他人的标注或网上信息，按你自己看到的判断；
- 不要改动“编号”“图片”和三列规程；
- 不要猜我们的方法会怎么判，标注表里也没有任何原始等级或模型结果。

## 标完之后
把填好的 `V36_标注表.csv` 发回给我（文件名不用改）。我会：
1. 计算你的标注与程序推出的新等级的一致率，以及“对照组”（规程修改后等级不变的图）上与原等级的一致率；
2. 用你的标注重新计算三条规程修改上 LUX 与各基线的准确率，配对检验；
3. 不一致的图逐张列出来给你复核。

如果有两个人分别标一遍，可以再算标注者之间的一致性（Cohen's κ）。不是必须的，但会让结果更有说服力。
