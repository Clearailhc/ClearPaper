# 双向同源选中与极简自然语言交互重构方案 (Unified Selection & Prompt-First Agent UX)

本方案旨在解决当前「源码区与预览区选中逻辑割裂」以及「右键菜单带有特定论文定制感」的问题，将源码与渲染画布收敛为一套**双向同源选中模型**与**单一自然语言优先（Prompt-First）浮层**。

## 用户确认的核心决策 (User Review & Critical Decisions)

> [!IMPORTANT]
> 以下设计已根据您的偏好对齐确认：
> - **双向同源选中（Source ↔ Preview 统一模型）**：无论在左侧 LaTeX 源码流还是右侧排版预览画布中划词或右键，均映射至同一个底层 LaTeX 选区状态，自动完成跨视图双向高亮与定位，并唤起**同一个**极简浮层。
> - **自然语言输入优先 + 3 个最基础通用动作**：彻底移除带有特定会议或目录名的硬编码选项（如“CVPR 学术润色”、“对齐 results/ 实验数据”等），浮层顶部直接聚焦自然语言输入框，下方仅保留 **润色（Polish）**、**精简（Condense）**、**扩写/改写（Rewrite）** 三个最基础的高频通用按钮。

---

## 1. 核心概念与体验升级 (Overview & Core Concept)

- **解决的核心痛点**：
  1. **消除交互割裂**：此前在源码区左键划词弹深色小黑条、右键弹白色长菜单，而在预览区划词无反应、只能按整块双击或右键，导致心智负担重且两栏状态不同步。
  2. **去特定化、回归通用写作工具本质**：写作工具的 AI 浮层应当像 Apple Intelligence / Cursor 的 `Cmd+K` 一样纯粹、克制、通用，任何领域的 LaTeX 手稿都能自然使用，而底层对工程文件（数据、图表、文献）的检索由后端 Agent 自动静默完成或通过 `@` 显式引用。

---

## 2. 用户体验与视觉设计 (User Experience & Visual Design)

### 2.1 双向同源选中流 (Bidirectional Homologous Selection)
1. **在 LaTeX 源码区划词或右键**：
   - 记录精确的章节路径与字符起止区间 `[start, end]`。
   - 右侧渲染预览画布中对应的段落/公式/图表块同步浮现柔和的钴蓝微光描边（`ring-1 ring-[#0066CC]/30 bg-[#0066CC]/[0.02]`），实现“改哪里、看哪里”的视觉同源。
2. **在渲染预览区划词或右键**：
   - 支持在预览画布中直接用鼠标划选任意文字句子，或右键点击任意段落、公式、表格、图片。
   - 系统自动将预览区的选中文本反向匹配定位到左侧对应 `.tex` 章节中的精确 LaTeX 源码片段（若划选了局部句子则精确匹配该句对应的 LaTeX 源码；若点击整块则匹配整个环境块），并自动将左侧源码平滑滚动并高亮定位到对应位置。
3. **共用唯一浮层菜单**：
   - 废除原先割裂的“深色左键小浮条 + 白色右键长菜单”双轨制。
   - 无论在源码还是预览中触发（右键唤起，或选中后点击轻巧锚点/快捷键），永远只呈现**唯一一个** Apple 毛玻璃浮层卡片。

### 2.2 纯粹自然语言优先浮层 (Prompt-First Floating Capsule)
- **第一层（核心焦点）**：自动聚焦的自然语言输入框（`告诉 AI 如何修改这段内容… 输入 @ 可引用工程文件`），支持直接回车执行任意指令（如“把这段改成被动语态”、“补充一段复杂度分析”、“根据实验记录更新这里的准确率”）。
- **第二层（仅 3 个基础通用动作）**：输入框下方仅以极简无边框文字链呈现三个通用动作：
  - `润色 Polish`（提升学术表达流畅度与清晰度）
  - `精简 Condense`（在不损失核心信息的前提下压缩篇幅）
  - `改写 Rewrite`（将草稿、中英混写或要点转化为规范 LaTeX 段落）
- **底部常驻 Spotlight 的协同**：当浮层未打开时，底部 Spotlight 依然保持极简折叠态，且底部预设同样同步精简为上述 3 个通用动作，保持全站语言的绝对统一。

### 状态与交互映射细节
- **预览文本到 LaTeX 源码的反向映射器 (`resolvePreviewSelectionToLatex`)**：
  - 当用户在右侧预览区划选一段渲染后的纯文本（如 `"calibrates atomic facts without retraining"`）时，系统首先定位其所属的渲染块原始 LaTeX 片段 `rawBlockLatex`，再通过剥离 LaTeX 宏指令（如 `\textbf{...}`、`\emph{...}`、`\cite{...}`）的模糊子串对齐算法，定位到左侧 `.tex` 源码中的精确起止偏移 `[start, end]`，从而保证 AI 修改后点击“写入 .tex”能**精准替换原句**，而非覆盖整章。
- **后端通用化提示词重构 (`/api/ai/polish`)**：
  - 将后端预设模式收敛为通用的 `polish`（学术润色）、`condense`（精简篇幅）、`rewrite`（规范改写与LaTeX化）与 `custom`（自由指令），去除硬编码的特定会议名称，同时保留底层自动检索工作区文件（`.tex`、`.bib`、实验记录）的上下文能力。
